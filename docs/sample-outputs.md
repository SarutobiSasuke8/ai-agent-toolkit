## Important Note

These samples are useful for showing the workflow end to end.

They are not the best possible outputs from the project.
Local small models are cheaper and easier to run, but they are usually weaker
than `gpt-4o` in style control, pacing, and factual compression.

That tradeoff is part of the project story:

- `ollama` proves the agent can run for free
- `openai` is the stronger quality path when API access is available
